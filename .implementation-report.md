## Design Decisions

### Why HYBRID?
1. **Native tooltips for elements:** Simple, zero-dependency, lightweight
2. **Custom indicator for frame:** Rich UI, real-time stats, better UX for aggregate data
3. **Best of both worlds:** Minimal overhead, maximum information

### Why `title` attribute?
- Works everywhere (no browser compatibility issues)
- No library dependencies
- Browser-native behavior (familiar to users)
- Automatically handles positioning and z-index

### Trade-offs Accepted
- **Tooltip delay:** Native `title` has 1-2 second delay (acceptable for dev tool)
- **No custom styling:** Can't customize tooltip appearance (acceptable, consistency is good)
- **Plain text only:** Can't show rich HTML (not needed for descriptions)

### Alternative Considered (Tippy.js)
- Would allow instant tooltips, custom styling, rich HTML
- Adds dependency, more complex initialization
- **Decision:** Not worth the complexity for dev-time verification feature
